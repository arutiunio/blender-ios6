### Raw handoff caveat

The raw development handoff/dependency archive contains absolute local build paths such as `/Users/.../Downloads`. A targeted credential scan did not find GitHub PATs, user mail credentials, provisioning profiles or private signing keys. CPython's upstream test suite contains its own public test PEM keys; these are test fixtures, not developer credentials. The raw archive is intentionally retained for build archaeology rather than presented as a polished SDK.
