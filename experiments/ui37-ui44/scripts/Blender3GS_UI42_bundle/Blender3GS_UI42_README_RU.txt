UI42 SAFE — A/B проверка визуальной регрессии UI41

Что меняется: только исходник wm_draw.c. Первая нативная отрисовка до Python,
перенос предпросмотров, экономия на повторном кадре и модульный UI39 Core
остаются как в UI41. На первом кадре НЕ переключаем View3D в BOUNDING BOX.
Важное ограничение: это диагностика новых артефактов UI41, а не обещанное
исправление старых белых прямоугольников GL4ES, существовавших до UI41.

Не меняет файлы Python, не отключает панели, не исправляет background.
Сохраняет рабочий UI41 IPA для установки обратно по --rollback.

Команда:
cd ~/Downloads && unzip -o Blender3GS_UI42_bundle.zip -d ~/Downloads && bash Blender3GS_UI42_BUILD_INSTALL.command

--check-only: только проверить, без изменений.
--resume: только после BACKUP + PATCH и неудачной компиляции.
--install-only: установить собранную UI42 IPA.
--rollback: вернуть исходную UI41 IPA на iPhone.

Для проверки: сравни UI41 и UI42 со скриншотом после полной загрузки.
Если новые артефакты остаются, нужен точный скриншот/видео. В логах
ищи 'UI42 SAFE: viewport_shading_unchanged' и 'UI40 FAST: native_frame_done'.
