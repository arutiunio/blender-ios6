Blender3GS UI37 — двухступенчатый запуск REAL Blender + эксперимент с белыми иконками
================================================================================

Основа: установленная UI36 с полноценным Python-интерфейсом (~227 панелей).
Это новая экспериментальная IPA, а не доказанное ускорение на реальном телефоне.
Touch v2, UI36 IPA и прежние резервные копии не перезаписываются.

Идея: штатный import bpy по-прежнему запускает bpy.utils.load_scripts(), но
bl_ui и bl_operators сначала импортируют только необходимые для первоначального
редактора модули. Все остальные исходные модули остаются внутри IPA. После
первого настоящего кадра WM_main вызывает по одному модулю каждой группы в
каждой итерации ОСНОВНОГО потока, затем перерисовывает правые панели. Нет
отдельной Python-нити, PocketJS или двух несовместимых GLES-контекстов.

Первые панели Object, Modifier, Material, Render, World, Scene и базовые
View3D/Outliner подготавливаются до снятия нативной заставки. Оставшиеся
30 модулей bl_ui и 15 модулей bl_operators догружаются постепенно. Проверять
полный набор инструментов только ПОСЛЕ появления "UI37 STAGE: batch=30/30".
При ошибке импорта модулей необходимо прислать полный лог; отсутствие ошибок
компиляции не гарантирует регистрацию всех 227 панелей.

Белые прямоугольники: для стандартных 16px иконок включён уже существующий
в Blender путь ICON_TYPE_BUFFER вместо текстуры-атласа GL4ES 1024x1024.
Это контролируемый диагностический обход, а не доказанное лечение всех артефактов.
Он может снизить скорость перерисовки меню и требует ~0.8 MB RAM под буферы.
Обычная плавность Viewport при partial redraw не меняется в исходниках.

В ФОНЕ: текущую проблему завершения PID эта сборка НЕ исправляет. iOS 6
может завершить приложение и при выставленном UIApplicationExitsOnSuspend=false;
надёжный autosave/restore потребует отдельной проверенной реализации без
фоновых GL-вызовов. Не храните важную несохранённую работу в эксперименте.

Сборка + установка одним блоком:
  cd ~/Downloads && unzip -n Blender3GS_UI37_bundle.zip -d ~/Downloads && bash Blender3GS_UI37_BUILD_INSTALL.command

Если после патча прервалась сборка:
  cd ~/Downloads && bash Blender3GS_UI37_BUILD_INSTALL.command --resume

Установить готовую UI37 без сборки:
  cd ~/Downloads && bash Blender3GS_UI37_BUILD_INSTALL.command --install-only

Вернуться на проверенную полноценную UI36 без повторной сборки:
  cd ~/Downloads && bash Blender3GS_UI36_BUILD_INSTALL.command --install-only

Собирать системный лог до открытия приложения:
  idevicesyslog 2>&1 | tee ~/Downloads/Blender3GS-ui37-device.log | grep --line-buffered -E 'Blender3GS UI37|Blender3GS UI17 PROPERTIES|Blender3GS UI31 PY|Blender3GS UI35 BOOT|Blender3GS UI28 LIFE|jetsam|crash'

Проверка: измерить время от запуска до первого настоящего окна; дождаться
"UI37 STAGE: batch=30/30"; проверить вкладки, выбор куба, белые иконки,
панели Modifier/Render/Material. Затем Home -> 10 секунд -> возврат без
переустановки IPA. Прислать лог и скриншот.

Если --check-only пишет STOP source hash, не изменяйте вручную файлы и
не запускайте --resume: значит текущие исходники отличаются от ожидаемых
UI36; приложите результат и актуальные WM/icons исходники для сверки.
